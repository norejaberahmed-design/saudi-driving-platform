# منصة مسار الرخصة السعودية

منصة تعليمية مستقلة تساعد المتقدمين على فهم متطلبات رخص القيادة في المملكة والاستعداد النظري والعملي. ليست جهة حكومية ولا تصدر الرخص ولا تمثل وزارة الداخلية أو الإدارة العامة للمرور.

## الحالة الحالية
مرحلة التأسيس. هذا المستودع يبدأ من نقطة نظيفة، وسيتم تطويره تدريجياً مع التحقق من كل مرحلة. لا توجد حالياً حسابات مستخدمين أو قاعدة بيانات أو تكامل مع أبشر.

## مبادئ المنتج
- المحتوى النظامي مرتبط بمصدر رسمي وتاريخ آخر مراجعة.
- الأسئلة التدريبية أصلية، ولا تُعرض على أنها أسئلة الاختبار الفعلي.
- لا نجمع كلمات مرور أبشر أو رموز التحقق.
- لا نعد المستخدم بالنجاح؛ مؤشر الجاهزية أداة تدريبية وليس درجة رسمية.
- لا ننفذ حجوزات أو معاملات حكومية دون تكامل رسمي وموافقة المستخدم.

## مصادر مرجعية أولية
- نظام المرور السعودي: https://laws.boe.gov.sa/
- منصة أبشر: https://www.absher.sa/
- دليل المتدرب النظري السعودي: https://www.ddc.sa/uploads/image/downloadables_pdf/Theoretical%20Driving%20Handbook%20Trainee-Moroor.pdf

يجب التحقق من صلاحية كل مصدر وتاريخه وشروط استخدامه قبل اعتماد محتواه داخل المنصة.

## خارطة الطريق
1. تأسيس تطبيق ويب عربي RTL ومتجاوب.
2. بناء هيكل المحتوى والإشارات والدروس.
3. إنشاء بنك أسئلة أصلي مع التفسير والتصنيف.
4. محرك اختبارات ومحاكاة وتحليل نقاط الضعف.
5. مدرب تعلم شخصي وخطة مراجعة.
6. دليل إجراءات الإصدار والتجديد والرخص الأجنبية بمراجع رسمية.
7. حسابات وحفظ التقدم ولوحة إدارة بعد وضع متطلبات الخصوصية والأمان.
8. اختبارات آلية وفحوصات جودة وأمن قبل أي نشر.

## التشغيل
تعليمات التشغيل ستضاف بعد تثبيت الهيكل التقني واعتماد ملفات المشروع الأولى.
