# مسار الرخصة السعودية

منصة تعليمية مستقلة باللغة العربية تساعد المتعلم على فهم موضوعات القيادة، التدرب على أسئلة أصلية، ومراجعة المسارات العامة لإصدار الرخصة وتجديدها.

> هذه المنصة ليست جهة حكومية، ولا تصدر الرخص، ولا تمثل الإدارة العامة للمرور أو وزارة الداخلية. ولا تدعي أن أسئلتها هي أسئلة الاختبار الرسمي.

## التقنية
- Next.js 15 App Router وReact 19 وTypeScript
- PostgreSQL وPrisma 6
- Better Auth لحسابات البريد وكلمات المرور والجلسات
- Zod للتحقق من مدخلات الخادم
- Vitest للاختبارات الوحدوية
- GitHub Actions لفحوصات الجودة

## الميزات الموجودة في المستودع
- واجهة عربية RTL ومتجاوبة مع الهاتف.
- إنشاء حساب وتسجيل دخول وخروج.
- مساحة متعلم تعرض المحاولات والتقدم المحفوظ.
- بنك أسئلة تدريبي قابل للتصفية حسب المجال وعدد الأسئلة (10/20/30)، مع ترتيب عشوائي وتصحيح على الخادم وشرح للإجابات.
- موسوعة أجهزة طريق أولية (45 عنصراً) محفوظة في PostgreSQL، مع واجهة API للعرض واختبارات إشارات مصححة ومخزنة على الخادم.
- سجل محاولات الاختبارات للمستخدم المسجل، وتحليل مجالات الضعف، وصفحة مراجعة الأخطاء المحفوظة.
- حفظ نتائج الاختبارات للمستخدم المسجل أو معرف زائر محلي.
- نموذج دروس مرتبط بالمصادر، مع عدم عرض الدروس غير المنشورة.
- حفظ إكمال الدروس للحسابات المسجلة.
- دليل إرشادي للإصدار والتجديد والرخص الأجنبية مع إحالات إلى القنوات الرسمية.
- واجهات API للدروس المنشورة: `GET /api/lessons` و`GET /api/lessons/:slug`.
- واجهات API للاختبارات: `GET/POST /api/quiz`، وسجل المحاولات `GET /api/attempts`.
- واجهات API لموسوعة الطريق: `GET /api/traffic-devices` و`POST /api/traffic-devices/attempt`.
- نقطة فحص لحالة اتصال قاعدة البيانات: `/api/health`.

## التشغيل المحلي
1. استخدم Node.js 20.9 أو أحدث.
2. انسخ `.env.example` إلى `.env`.
3. ضع عنوان PostgreSQL المجمّع (pooled) في `DATABASE_URL` وعنوان الاتصال المباشر في `DIRECT_URL` لاستخدامه في عمليات الترحيل.
4. أنشئ سراً عشوائياً قوياً لا يقل عن 32 حرفاً في `BETTER_AUTH_SECRET`.
5. اضبط `BETTER_AUTH_URL=http://localhost:3000`.
6. شغّل:

```bash
npm install
npm run db:deploy
npm run db:seed
npm run dev
```

ثم افتح `http://localhost:3000`.

## إعداد قاعدة البيانات
لا يحتوي المستودع على بيانات اتصال أو كلمات مرور. تحتاج بيئة التشغيل إلى قاعدة PostgreSQL فعلية. لا يتم إنشاء قاعدة بيانات سحابية أو دفع أي رسوم تلقائياً.

## الحوكمة والسلامة
- الإجابات الصحيحة لا تُرسل للمتصفح قبل تسليم الاختبار.
- لا تجمع المنصة كلمة مرور أبشر أو OTP أو رقم الهوية.
- لا تنشر أي مادة نظامية إلا بعد ربطها بمصدر موثوق وتاريخ مراجعة وموافقة تحريرية.
- عناصر موسوعة الطريق الحالية دفعة تدريبية أولية من 45 عنصراً وليست الكتالوج السعودي الكامل؛ الأكواد والمراجع المحددة ما زالت تحتاج مطابقة نهائية ومراجعة بشرية.
- لا يوجد تكامل مع أبشر أو حجز حكومي أو دفع إلكتروني.
- تفاصيل البنية وحدود الأمان في `docs/architecture.md`.

## خارطة الطريق
- استكمال محتوى المناهج السعودية وتوثيق كل درس وسؤال.
- أدوات إدارة ومراجعة ونشر المحتوى مع سجل تغييرات.
- اختبارات محاكاة أطول وتحليل الضعف حسب المحور.
- دعم مسارات الإصدار والتجديد والرخص الأجنبية بتفاصيل رسمية محدثة.
- تحسين إمكانية الوصول والأداء والأمان، ثم اختبار قبول شامل قبل النشر.
